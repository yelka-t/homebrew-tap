# Sapphire Homebrew Tap

Homebrew formulae for [Sapphire](https://github.com/yelka-t) command-line tools.

## Install

```sh
brew tap yelka-t/tap
brew install sapphire
```

`brew tap yelka-t/tap` resolves to this repository (`yelka-t/homebrew-tap`); Homebrew drops the `homebrew-` prefix.

Once tapped, upgrades come through the usual channel:

```sh
brew upgrade sapphire
```

## Formulae

Formula definitions live in `Formula/`. Each is published automatically when a new CLI release is cut.
